# 抖音优化 · 精简版 (Douyin Optimized Lite)

从 [WhiteSevs/TamperMonkeyScript](https://github.com/WhiteSevs/TamperMonkeyScript) 的「抖音优化」重构而来的油猴脚本，剔除原版 300+ 项设置，聚焦五项核心功能：

- 🎯 **记住选择画质** —— 在播放器里手动选一次清晰度，脚本通过 `sessionStorage["MANUAL_SWITCH"]`（官方路径）记住并在下次自动恢复；也支持强制指定档位
- 🔓 **解锁更高画质** —— 监控播放器画质变化，被抖音降级时自动强制回目标档位（开关控制，设置持久保存）
- 🚫 **自定义视频过滤器** —— 拦截推荐/关注/朋友/精选/用户主页/相关推荐/合集/搜索等接口，按规则移除命中视频（广告、带货、直播卡片、关键词等）
- 📊 **屏蔽统计** —— 按规则累计已移除视频数，面板独立页签查看明细；统计存 sessionStorage，关闭标签页/浏览器自动清零
- ⚡ **预加载下一条视频** —— 过滤移除较多时按原始请求方法主动请求下一页并缓存过滤结果，抖音请求时直接命中缓存，减少等待

对比原版：685 KB → ~80 KB（-88%），零 `@require` 外部依赖。

## 安装

1. 安装 [TamperMonkey](https://www.tampermonkey.net/) / ScriptCat / ViolentMonkey
2. 新建脚本，粘贴 [`douyin-optimized-lite.user.js`](douyin-optimized-lite.user.js) 全文保存（或通过 Raw 链接安装）
3. 打开 [douyin.com](https://www.douyin.com/)，油猴菜单 →「抖音优化：设置」

## 功能说明

### 画质

| 模式 | 行为 |
|---|---|
| 记住手动选择（推荐） | 播放器里选一次画质，脚本自动记住并在下次恢复 |
| 强制 | 始终使用指定档位（最高超清 4K） |
| 不干预 | 完全不写画质配置 |

「解锁更高画质」开启后：播放器若把画质降级（如 4K→1080P），脚本每秒检测并自动强制回目标档位。开关状态持久保存，刷新不重置。

### 视频过滤器

面板 →「自定义视频过滤器」→「导入规则 JSON」→ 选择 [`rules/抖音优化-视频过滤规则.json`](rules/抖音优化-视频过滤规则.json)。

共 22 条规则（可直接导入，也可自行增删）：

| 规则 | 机制 |
|---|---|
| 屏蔽用户名含「新闻」的作者 | 昵称关键词 |
| 屏蔽华为/余承东/花粉相关 | 文案/话题/标签/昵称/合集名关键词（含余大嘴/大嘴/菊厂/华子） |
| 屏蔽小米/雷军/米粉相关 | 同上（含雷布斯/军儿/雷总/卢十瓦/Are you OK） |
| 屏蔽汽车相关 | 品牌/车型/购车/驾考等 ~75 词 |
| 屏蔽广告视频 | 字段级 `isAds`（接口自带标记，零误杀） |
| 屏蔽商品推广/带货 | 字段级 `isProduct` |
| 屏蔽广告话术 | ~55 个带货/引流关键词（仅匹配文案不匹配作者名） |
| 屏蔽直播/直播间卡片 | 字段级 `isLive` |
| 屏蔽男权/女权对立话题 | 性别对立/婚恋引战关键词（已剔除高风险泛词） |
| 屏蔽AI生成视频 | 字段级 `isAigc`（接口自带标记，零误杀）+ 关键词兜底（横幅文案/话题标签） |
| 屏蔽网赚/刷单/荐股/博彩引流 | 引流话术关键词 |
| 屏蔽短剧/小说推文引流 | 推文引流关键词 |
| 屏蔽卖课/知识付费 | 卖课话术 |
| 屏蔽玄学/算命/风水 | 玄学关键词（含作者昵称） |
| 屏蔽探店/团购广告 | 探店推广话术 |
| 屏蔽成功学/鸡汤 | 鸡汤话术 |
| 屏蔽医疗养生谣言 | 谣言关键词 |
| 屏蔽超短视频（<3秒） | `duration < 3000`（数值比较） |
| 屏蔽卖惨/苦情营销 | 卖惨关键词 |
| 屏蔽零点赞视频（默认关） | `diggCount = 0`，需要时手动启用 |
| 作者黑名单（函数） | 自定义函数，把作者名填进 `BLOCK` 数组即可生效 |

### 屏蔽统计

- 油猴菜单实时显示「已屏蔽 N 条（点击查看完整明细）」，点击直达统计页
- 面板「屏蔽统计」页签：累计总数 + 按规则明细 + 一键清零
- 统计按规则 uuid 累计，新增/改名规则自动反映
- 存储于 sessionStorage：关闭标签页/浏览器自动清零

### 预加载下一条视频

- 单次过滤移除 ≥ 5 条时，按原始请求方法（GET/POST）主动请求下一页
- POST 接口在 body 里替换游标，避免拿到空页
- 过滤结果按 URL 缓存（LRU 最多 3 个），抖音请求同一 URL 时直接命中
- 用原始 fetch 发请求（绕过自身 hook），避免死循环

### 性能

- 正则编译缓存、规则内存缓存、统计写入合并、响应处理去重
- 滚动分页全同步过滤（实测每响应 < 12ms）
- 规则数量增长不影响加载速度

## 规则写法速查

| 属性类型 | 写法 |
|---|---|
| 字符串（desc/nickname/textExtra…） | 正则：`电影\|解说` |
| 数值（duration/diggCount…） | 比较：`>180000`、`<=300`、`=300` |
| 布尔（isAds/isLive/isProduct…） | `true` / `false` |
| 自定义函数 | 函数体，`return true` 表示过滤，`data.transformAwemeInfo` 取字段，fetch 接口支持 `await` |

作用域：规则可限定生效接口（推荐/关注/搜索等），`all` 为全部。
